# Contributing to EarthSwap

Thank you for your interest in contributing to EarthSwap!

## How to contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Run `bun run check` to ensure no lint or type errors
5. Commit your changes: `git commit -m "Add your feature"`
6. Push to your fork and open a Pull Request

## Development setup
